# Lean Canvas - SekolahKu

## 1. PROBLEM
- Schools still rely on paper-based or fragmented digital systems for student/teacher management
- No centralized platform for learning materials, profiles, and communication
- Small schools lack budget for expensive enterprise school management software
- Complex Supabase setup barriers prevent immediate adoption
- No real-time notification system for important school updates

## 2. SOLUTION
- Web-based school management system with centralized student/teacher data
- Three roles: Students, Teachers, School Administration
- Demo mode works immediately without Supabase configuration (localStorage)
- Push notifications via FCM/OneSignal for important updates
- Realtime data sync via Supabase when configured
- Neo-Brutalist UI design for modern, usable interface

## 3. UNIQUE VALUE PROPOSITION
- Free, lightweight school management system that works out-of-the-box in demo mode
- Immediate usability without backend configuration
- Push notification capability to mobile devices (Android iOS via PWA)
- Realtime updates and modern UI based on Neo-Brutalism design system
- Three-user role support in single platform

## 4. UNFAIR ADVANTAGE
- Demo mode enables instant usage without Supabase setup
- Push notification system (FCM/OneSignal) not commonly in free school tools
- Neo-Brutalist UI design system with consistent visual language
- Built on Supabase with realtime capabilities and authentication
- Open source nature allows customization and community adoption

## 5. CUSTOMER SEGMENTS
- **Students**: View profiles, notifications, school information
- **Teachers**: Post learning materials, manage quizzes, view student data
- **School Administration/Principal**: Full management, user accounts, reports, settings

## 6. KEY METRICS
- Number of active schools/deployments
- Student and teacher adoption rate per school
- Push notification engagement/read rates
- System uptime and availability
- User satisfaction scores
- Time-to-first-value (how quickly users can start using)

## 7. CHANNELS
- Web browser (PWA compatible - works on desktop and mobile)
- "Add to Home Screen" for mobile app-like experience
- GitHub/Source code sharing for developers
- Educator communities and school networks
- Word-of-mouth through demo mode accessibility

## 8. COST STRUCTURE
- Supabase hosting and database costs (free tier available)
- Development and maintenance time
- Potential FCM/OneSignal service costs at scale
- Domain hosting (if custom domain needed)
- Third-party integrations (payment gateways, email services)

## 9. REVENUE STREAMS
- Currently free/opensource (no direct revenue in MVP)
- Potential premium features: advanced reporting, integrations
- Hosting/managed service fees for schools
- Customization services for specific school needs
- Enterprise tier for multi-school organizations
